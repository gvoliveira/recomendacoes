### *Um resumo com materiais úteis para estudos na área de desenvolvimento*

**Gilberto Viana de Oliveira** · última revisão: outubro de 2026

Primeiramente, pra quem não me conhece, sou Gilberto, professor do curso Técnico em Informática e também do curso de Análise e Desenvolvimento de Sistemas (ADS).

Criei este repositório com o objetivo de agrupar algumas informações para meus alunos. Em diversas aulas sugiro ferramentas, apostilas, livros, canais etc. Muitas vezes (quem é professor sabe), a gente acaba esquecendo de citar alguma referência naquele exato momento. Sendo assim, este repositório reúne a maioria dessas indicações de maneira organizada. Também deixo aberto para quem queira contribuir com mais materiais relacionados. 👊

> **Legenda de níveis:** **1** = iniciante · **2** = intermediário · **3** = avançado.
> Quando um material cobre mais de um nível, aparece como "1 a 3", por exemplo.

## IDEs e ferramentas

Algumas IDEs instaláveis, bem como alternativas online e ferramentas que me ajudam no dia a dia.

### Algoritmos e fluxogramas

- [Portugol Studio Online](https://portugol.dev/) — versão online do Portugol Studio, direto no navegador.
- [Portugol Studio](https://univali-lite.github.io/Portugol-Studio/) — IDE instalável para aprender a programar em português estruturado.
- [VisualG](https://visualg3.com.br/baixar-o-visualg3-0/) — IDE instalável de pseudocódigo (Windows).
- [Lucidchart](https://www.lucidchart.com/) — criação de fluxogramas online (plano gratuito limitado).
- [diagrams.net (draw.io)](https://app.diagrams.net/) — alternativa gratuita para fluxogramas e diagramas.

### Linguagem C

- [OnlineGDB](https://www.onlinegdb.com/online_c_compiler) — compilador de C online, sem instalar nada.
- [Code::Blocks (MinGW)](https://www.codeblocks.org/downloads/binaries/) — IDE instalável. No Windows, baixe a versão **com MinGW** (arquivo `...mingw-setup.exe`) para já ter o compilador.

### Desenvolvimento web

- [VS Code](https://code.visualstudio.com/) — editor de código gratuito e muito usado.
- [Sublime Text](https://www.sublimetext.com/) — editor leve e rápido.
- [CodePen](https://codepen.io/pen/) — editor online de HTML, CSS e JavaScript.

### Design, organização e mídia

- [Figma](https://www.figma.com/) — design de interfaces e protótipos.
- [Trello](https://trello.com/) — organização de tarefas em quadros kanban.
- [Notion](https://www.notion.so/) — anotações e organização de projetos.
- [Inkscape](https://inkscape.org/pt-br/) — editor de imagens vetoriais.
- [Shotcut](https://shotcut.org/) — editor de vídeo gratuito.

### Extensões e fontes do VS Code

- [Color Highlight](https://marketplace.visualstudio.com/search?term=Color%20Highlight&target=VSCode&category=All%20categories&sortBy=Relevance) — destaca cores (hex, rgb) no próprio código.
- [Fira Code](https://github.com/tonsky/FiraCode) — fonte com ligaduras (`=>`, `!==` etc.).
- [Live Server](https://marketplace.visualstudio.com/search?term=Live%20Server&target=VSCode&category=All%20categories&sortBy=Relevance) — servidor local com recarregamento automático.
- [Prettier](https://marketplace.visualstudio.com/search?term=Prettier&target=VSCode&category=All%20categories&sortBy=Relevance) — formatação automática de código.
- [Symbols](https://marketplace.visualstudio.com/search?term=Symbols&target=VSCode&category=All%20categories&sortBy=Relevance) — tema de ícones para os arquivos.

## Como contribuir

Descobriu algo legal? Pois venha contribuir! Siga o passo a passo:

1. Abra uma **issue** com o link e uma breve descrição, ou faça um **fork** e envie um **Pull Request**.
2. Siga o padrão das listas: `- [Nome](link) — descrição curta.`
3. Prefira materiais **gratuitos** e, quando possível, **em português**.
4. Se puder, indique o nível (**1**, **2** ou **3**, conforme a legenda no topo) e confira se o link está funcionando.

Encontrou um **link quebrado** ou uma informação desatualizada? Abra uma issue também.

QUE A FORÇA ESTEJA CONOSCO! SEMPRE!!
